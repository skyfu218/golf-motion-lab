# Golf Motion Lab

手機高爾夫揮桿視訊分析 Web App 第一版原型。

## 目前可用功能

- 選擇後側 DTL 或側面 Face-on 拍攝模式。
- 瀏覽器相機預覽與錄影（需透過 localhost 或 HTTPS 開啟）。
- 匯入手機既有影片並逐格／慢速播放。
- 內建 Driver、7 號鐵、Pitch、Putter 四支 8 秒示範影片。
- 依影片長度、方向與抽樣亮度提供拍攝品質回饋。
- 可拖曳旋轉、滾輪縮放的 3D 泡泡人。
- 後側、側邊、俯視及自由旋轉視角。
- P1–P8 揮桿階段與影片時間軸同步。
- 依 DTL／Face-on 顯示不同的人工動作檢核項目。
- 匯出純文字分析摘要。
- 顯示本裝置開啟、分析與 Demo 使用次數。
- 右下角顯示臺灣運動健康科技學會 Logo、名稱與更新月份。

## 啟動方式

在 macOS Finder 雙擊：

`啟動 Golf Motion Lab.command`

腳本會啟動只供本機使用的網頁伺服器並開啟：

`http://127.0.0.1:8766/`

若埠號已被使用，可在終端機執行：

```sh
python3 -m http.server 8767
```

再開啟 `http://127.0.0.1:8767/`。

## 第一版的重要邊界

- 3D 泡泡人目前是可互動的揮桿階段示意模型，尚未由匯入影片重建。
- 畫面上顯示的角度是示意階段值，不是對使用者身體的測量結果。
- 目前自動檢查的是影片長度、方向與亮度；動作技術項目由使用者或教練人工逐格確認。
- 影片只在瀏覽器本機處理，沒有上傳後端。
- 頁尾計數目前使用瀏覽器 `localStorage`，代表本裝置使用情況，不是跨裝置的全站總流量；正式流量由 Firebase Analytics／Hosting 後台查看。
